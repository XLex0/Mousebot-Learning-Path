# 🧠 Erick's Mousebot Learning Path

This repository documents my personal journey to design and build a complete **micromouse system** capable of solving mazes—starting from maze generation and solving algorithms.

---

## 🚀 Project Purpose

This is not just a project—it's a **learning path**. The goal is to progressively explore the key components behind autonomous maze-solving robots through practical experimentation and coding. I plan to implement everything in a real-world micromouse robot.

---

## 🔄 Project Phases

### 📐 Phase 1: Maze Generation
- Implementing structured maze generation algorithms:
  - Recursive Backtracker
  - Prim’s Algorithm
  - Kruskal’s Algorithm
  - Recursive Division
- Exporting mazes as:
  - 2D matrices (`.json`, `.txt`)
  - Black-and-white images (`.png`)

### 🧠 Phase 2: Maze Solving Algorithms
- Developing core pathfinding algorithms such as:
  - Depth-First Search (DFS)
  - Breadth-First Search (BFS)
  - A* (A-star)
  - Wall-following
  - Flood Fill
- Testing solutions and visualizing paths.
